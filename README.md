# Kotai

Kotai is a macOS menu bar app for switching OpenRouter usage between personal
and work accounts. It supports Cursor and other OpenAI-compatible clients.

## How it works

```text
Client → ngrok → Kotai → active OpenRouter account
```

- OpenRouter keys and the ngrok authtoken stay in the macOS Keychain.
- Clients authenticate with a separate proxy token generated by Kotai.
- Switching **Personal** or **Work** takes effect immediately.
- Kotai listens only on `127.0.0.1:18742`; ngrok provides the public HTTPS URL.

## Requirements

- macOS 14 or newer
- Xcode 16 or newer
- A free [ngrok](https://ngrok.com/) account
- Two OpenRouter API keys

```bash
brew install ngrok
swift build
swift run Kotai
```

On first launch, the setup wizard asks for:

- Personal and work OpenRouter keys
- Your [ngrok authtoken](https://dashboard.ngrok.com/get-started/your-authtoken)
- A generated Kotai proxy token

Kotai starts ngrok and discovers your account's stable dev URL automatically.

## Client configuration

Use the generated proxy token as the client API key.

### Cursor

```text
https://abc123.ngrok-free.app/cursor/v1
```

In **Cursor Settings → Models → API Keys**:

1. Enable the OpenAI API key and paste the proxy token.
2. Enable **Override OpenAI Base URL** and paste the Cursor URL.
3. Add and select the desired OpenRouter model IDs.

### Other OpenAI-compatible clients

```text
https://abc123.ngrok-free.app/v1
```

Use the generic URL with clients that support the OpenAI wire format and a
custom base URL. Anthropic-native clients are not supported.

## Notes

- Kotai, ngrok, and the Mac must be running for requests to work.
- Anyone with the proxy token can use the active OpenRouter account. Rotate it
  in Kotai and connected clients if exposed.
- Prompt data transits ngrok, Cursor when applicable, and OpenRouter.
- ngrok free-plan request and bandwidth limits apply.
- OpenRouter's Cursor integration is beta. Some Cursor features may bypass
  custom API keys or base URLs.
